# Orion

Orion is a small RISC-V SoC and RTL playground centered around:
- a custom CPU core
- Wishbone-based interconnect and peripherals
- simulation-first development with Verilator and MkDocs docs

## Project Layout
```text
rtl/        synthesizable RTL
sim/        Verilator simulation harness
sw/         software and test programs
docs/       MkDocs content
```
